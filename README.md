# DocuMind AI: Local RAG Knowledge Bot & CI/CD Automated Pipeline

![AI Pipeline CI/CD](https://github.com/Prabu1301/DocuMind-AI-Self-Project/actions/workflows/ai-ci-cd.yml/badge.svg)

## Overview
A lightweight, container-ready Retrieval-Augmented Generation (RAG) knowledge retrieval engine built with **ChromaDB**, **SentenceTransformers (all-MiniLM-L6-v2)**, and automated via **GitHub Actions CI/CD**.

## Architecture & Features
- **Semantic Search Vector Store:** Local persistent vector storage using ChromaDB.
- **Embedded Intelligence:** MiniLM local embeddings for sub-second similarity matching.
- **Cloud Automation Quality Gate:** Fully automated `pytest` execution on every push using GitHub Actions Ubuntu runners.
